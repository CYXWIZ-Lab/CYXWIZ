Deploy to Autoencoder Training
The pipeline exports two tensors: the raw window sequences [N, 60, 6] for the LSTM encoder, and the scalar feature vector [N, 34] for a parallel dense branch. Both are automatically connected to the DataInput nodes in the Node Editor. The model sees both representations simultaneously — temporal patterns and statistical summaries.

The complete data-to-training workflow. Data Studio prepared the time-series windows, extracted features, and normalized everything. The Node Editor receives the ready tensors. You design the autoencoder architecture and start training — all within CyxWiz. High reconstruction error on the validation set identifies the anomalous machines.
🎯
Why this matters: In a typical workflow, this pipeline would require a Jupyter notebook (data loading), separate Python preprocessing scripts (windowing, feature extraction), and manual NPZ file creation before even starting model design. CyxWiz Data Studio collapses all of that into a single visual pipeline that runs in 28 seconds, is saved as a reusable JSON file, and hands off directly to the model builder. No code, no files, no friction.
