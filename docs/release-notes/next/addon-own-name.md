**An add-on is shown under its plugin's own name and description.** The signed add-on package now carries the name and description its plugin declares, and the add-on cards in the CyxWiz Installer and in **Preferences > Installed packs**, the installation summary, the uninstall confirmation and the Engine's log use them. Any plugin's add-on shows under its own words; before, only Simulation (MuJoCo) had a name and every other add-on showed under its plugin id. A package made before this change shows as it did.
