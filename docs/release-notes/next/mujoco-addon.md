**Simulation (MuJoCo), the first add-on.** MuJoCo environments for reinforcement learning, the 3D viewport and the Environment Library now come as an optional signed package. Tick **Simulation (MuJoCo)** under **Individual components > Add-ons** in the CyxWiz Installer, or choose **Preferences > Installed packs > Add-ons > Install add-on...** in the Engine; it is ready the next time the Engine starts. No profile installs it for you, and **CPU only** never removes it.
