# CyxWiz Support

CyxWiz is in active pre-release development.

For reproducible defects and focused feature proposals, use [GitHub Issues](https://github.com/CYXWIZ-Lab/CYXWIZ/issues). Include the commit, operating system, build type, requested and resolved compute device, exact steps, expected result, relevant logs, and a minimal graph or dataset sample when redistribution is allowed.

Use [GitHub Discussions](https://github.com/CYXWIZ-Lab/CYXWIZ/discussions) for usage and design questions when available. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Do not post credentials, personal information, proprietary data, full large datasets, or private business documents.
